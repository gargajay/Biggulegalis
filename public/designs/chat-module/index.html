Developer Handoff Notes

No group chat: Bar Council areas list members only. Chats are one-to-one between members.
Personal chat request: Member profile sends a message request. Request inbox supports accept and deny before a private chat opens.
Message payload: Design supports text, emoji, link previews, image previews, and document cards.
Sender names: Every message bubble displays the sender name, including the current user as You.
